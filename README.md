# penetrate-my-book

Считает слова в тексте, догружает значения из словаря и помогает учить незнакомые. Сейчас есть английский и немецкий. У каждого языка свои книги и свой список знакомых слов.

Нужен Python 3. Сторонние пакеты не ставятся: `requirements.txt` пустой.

## Сайт

```bash
make ui
```

Открыть http://127.0.0.1:8000. Остановка: Ctrl-C.

На первом экране выберите имя или введите новое. Пароля нет. «Сменить пользователя» возвращает к этому экрану.

На списке книг переключатель «Английский» / «Немецкий». Выбор запоминается. В списке только книги этого языка. Счётчик «Слова которые я знаю» тоже только для него. Слово, выученное в английском, в немецком остаётся неизвестным. У другого пользователя свой список.

- «Добавить книгу» загружает `.txt` в UTF-8 или Windows-1251 в выбранный язык. Имя книги берётся из имени файла, язык дописывается в таблицу: `murik.txt` по-английски становится `murik-en`. На сайте суффикс не показывается. Повторная загрузка того же имени в том же языке заменяет книгу.
- «Синхронизировать» скачивает значения слов, которых ещё нет в словаре этого языка. Пока идёт загрузка, написано «Синхронизация…». Если API отвечает лимитом, появляется «Достигнут рейт лимит»: нажмите кнопку позже, уже скачанное сохранится. Когда качать больше нечего, кнопка исчезает.
- «Учить слова» открывает неизвестные слова по частоте. «← Назад» и «Дальше →» листают слово, стрелки влево и вправо делают то же самое. «Выучил» запоминает слово для всех ваших книг этого языка.

Позиция в уроке держится, пока работает `make ui`. После перезапуска урок снова начинается с самого частого неизвестного слова. Отмеченные слова при этом остаются.

## Окно

```bash
make desktop
```

Те же экраны и те же правила, что на сайте. База общая: `storage/knowledge.db`. Стрелки влево и вправо листают слово, Escape возвращает к списку книг. Окно — это Tk из стандартной библиотеки, отдельные пакеты не ставятся. Закрытие окна останавливает программу.

Tk есть в обычном Python на Windows, macOS и Linux. Сборка Homebrew его не включает, пока не поставлен Tk для той же версии Python:

```bash
brew install python-tk@3.14
```

На Linux пакет называется `python3-tk`. В установщике с python.org для Windows Tk уже есть.

## Команды

`make` без цели печатает справку.

```bash
make parse FILE=murik.txt LANG=en
make parse FILE=buch.txt LANG=de
make synk TABLE=murik-en
make csv TABLE=murik-en
make desktop
make db
```

`FILE` по умолчанию `murik.txt`, `LANG` по умолчанию `en`, `TABLE` по умолчанию `murik-en`.

`parse` разбирает файл и записывает книгу выбранного языка. Это то же действие, что «Добавить книгу». Таблица книги пересоздаётся.

`synk` и `csv` узнают язык по суффиксу таблицы: `murik-en`, `buch-de`. `synk` качает значения в словарь этого языка. В консоли идут строки `1/100 word`. Если слов не осталось: `nothing to fetch`. При лимите: `rate limit reached`.

`csv` пишет `storage/<таблица>.csv`.

`db` открывает `storage/knowledge.db`. Выход: `.quit` или Ctrl-D.

Те же команды без make:

```bash
python main.py --parse murik.txt en
python main.py --synk murik-en
python main.py --create-csv murik-en
python main.py --ui
python main.py --desktop
```
